Detail Praktikum

Deskripsi

Praktikum ini memperkenalkan grafika komputer melalui HTML Canvas 2D. Gambar berasal dari data koordinat, ukuran, warna, dan bentuk yang diperbarui JavaScript lalu digambar kembali pada setiap frame.

CREATE CANVAS → DRAW PRIMITIVE → SET COLOR & POSITION → ANIMATE → ADD INTERACTION

Canvas & Koordinat

Titik (0, 0) berada di kiri atas. Nilai x bertambah ke kanan dan y bertambah ke bawah.

Primitive & Geometry

Rectangle, line, circle, dan triangle dibentuk dari posisi titik, ukuran, radius, garis, serta warna.

Animasi Berbasis Frame

requestAnimationFrame() menjalankan update dan draw berulang agar objek terlihat bergerak.

Interaksi Pengguna

Mouse menampilkan koordinat dan menangkap bola. Keyboard mengontrol objek dan animasi.

Pola Input Keyboard

  • Event-based: C, R, dan Space menjalankan satu aksi setiap kali ditekan.
  • State-based: Arrow atau WASD menggerakkan kotak selama tombol ditahan.
  • Boundary checking: objek dibatasi agar tidak hilang dari canvas.

USER INPUT → UPDATE DATA → DRAW FRAME → DISPLAY → REPEAT

Challenge & Pengujian

Challenge Tangkap Bola menambah skor, mengubah warna, arah, dan kecepatan bola ketika berhasil diklik.

  • Rectangle, line, circle, dan triangle tampil dengan warna berbeda.
  • Animasi, koordinat mouse, input keyboard, dan multi-key movement bekerja.
  • Boundary checking menjaga objek utama tetap berada di dalam canvas.

Graphics Pipeline

DATA → COORDINATE → PRIMITIVE → DRAWING → FRAME → PIXEL / IMAGE. Alur ini menjadi pengantar menuju WebGL pada pertemuan berikutnya.

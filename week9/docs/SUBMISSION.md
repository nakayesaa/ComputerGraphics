## Urutan demo langsung

1. Sebutkan anggota dan konsep toolbox.
2. Scene `01_BLOCKOUT_RECONSTRUCTION`: cube badan, tutup, grip, duplicate tiang, transform numerik, dan scale.
3. Scene `02_EXTRUDE_INSET_RECONSTRUCTION`: rim inset dan rongga hasil extrude.
4. Scene `03_LOOP_BEVEL_RECONSTRUCTION`: Edit Mode, edge selection, loop horizontal, dan efek Bevel.
5. Scene `04_FINAL_TOOLBOX`: Outliner, 9 mesh, signature curve, serta parenting.
6. Pilih pengunci/rib/badan: Mirror, Array count 5, Solidify 0.06, Bevel; matikan/nyalakan untuk menunjukkan efeknya.
7. Body Edit Mode: vertex/edge/face inspection, Merge by Distance, recalculate normals, dan Face Orientation.
8. Frame 1/41/80: tutup tertutup/terbuka/tertutup; handle mengikuti.
9. Akhiri dengan hasil akhir serta kesiapan UV/material.
